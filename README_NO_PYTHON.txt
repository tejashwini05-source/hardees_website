RUN THIS WEBSITE WITHOUT PYTHON

OPTION 1 - VS CODE LIVE SERVER (RECOMMENDED)
1. Extract this ZIP file.
2. Open the hardees_fresh_site folder in Visual Studio Code.
3. If prompted, install the recommended extension: Live Server (by Ritwick Dey).
   Or open Extensions (Ctrl+Shift+X), search for "Live Server", and install it.
4. Open index.html.
5. Right-click inside the editor and choose "Open with Live Server".
6. Your browser will open the website, usually at http://127.0.0.1:5500/.

OPTION 2 - OPEN DIRECTLY
1. Open the extracted hardees_fresh_site folder.
2. Double-click index.html to open it in your browser.

This is a static HTML/CSS/JavaScript website. Python and npm are not required.
